# Python - Test-Driven Development

## Description
This project focuses on **Test-Driven Development (TDD)** using Python 3. It covers writing unit tests with the `unittest` module and doc tests using `doctest`. The goal is to write clean, robust code by defining test cases and edge cases prior to implementation.

## Tasks & Requirements

### Task 0: Integers Addition
* **Files:** `0-add_integer.py`, `tests/0-add_integer.txt`
* **Function:** `add_integer(a, b=98)`
* **Description:** Adds two integers or floats (casted to integers). Raises a `TypeError` if inputs are not integers or floats.

### Task 1: Divide a Matrix
* **Files:** `2-matrix_divided.py`, `tests/2-matrix_divided.txt`
* **Function:** `matrix_divided(matrix, div)`
* **Description:** Divides all elements of a matrix by `div`, rounded to 2 decimal places.

### Task 2: Say My Name
* **Files:** `3-say_my_name.py`, `tests/3-say_my_name.txt`
* **Function:** `say_my_name(first_name, last_name="")`
* **Description:** Prints `My name is <first_name> <last_name>`.

### Task 3: Print Square
* **Files:** `4-print_square.py`, `tests/4-print_square.txt`
* **Function:** `print_square(size)`
* **Description:** Prints a square with the `#` character given a valid size integer.

### Task 4: Text Indentation
* **Files:** `5-text_indentation.py`, `tests/5-text_indentation.txt`
* **Function:** `text_indentation(text)`
* **Description:** Prints text with 2 new lines after each `.`, `?`, and `:` character.

### Task 5: Max Integer - Unittest
* **Files:** `tests/6-max_integer_test.py`
* **Description:** Unittests for the function `max_integer(list=[])` using Python's `unittest` framework.

### Task 6: Matrix Multiplication
* **Files:** `100-matrix_mul.py`, `tests/100-matrix_mul.txt`
* **Function:** `matrix_mul(m_a, m_b)`
* **Description:** Multiplies two matrices after thorough input validation.

### Task 7: Lazy Matrix Multiplication
* **Files:** `101-lazy_matrix_mul.py`, `tests/101-lazy_matrix_mul.txt`
* **Function:** `lazy_matrix_mul(m_a, m_b)`
* **Description:** Multiplies two matrices using the `NumPy` library.

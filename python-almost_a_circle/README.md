# Python - Almost a Circle

## Description
This project covers foundational to advanced Python Object-Oriented Programming (OOP) concepts by building a class hierarchy rooted at `Base`, with derived classes `Rectangle` and `Square`.

## Objectives
* Learn and practice inheritance and class structures in Python.
* Implement private instance attributes with getters and setters for validation.
* Apply unit testing using Python's `unittest` module.
* Handle JSON data serialization and deserialization.

## Testing
Run all unit tests with:
```bash
python3 -m unittest discover tests

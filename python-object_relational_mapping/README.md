# Python - Object-Relational Mapping (ORM)

## Project Overview
This project bridges Python scripts with MySQL databases using both the `MySQLdb` module for direct SQL execution and `SQLAlchemy` for Object-Relational Mapping (ORM).

## Requirements
* **Environment:** Ubuntu 20.04 LTS
* **Python Version:** 3.8.5
* **MySQL Server:** 8.0.x
* **Libraries:** `MySQLdb` (v2.0.x), `SQLAlchemy` (v1.4.x)
* **Style:** `pycodestyle` (v2.8.*)
